# Website Portfolio Cá Nhân

## 1. Sản phẩm này là gì?

Đây là trang web giới thiệu bản thân và 3 dự án học tập cá nhân. Website được chuẩn bị dành riêng cho các nhà tuyển dụng xem xét khi ứng tuyển vị trí thực tập.

## 2. Demo

👉 <https://an.github.io/portfolio/>

## 3. Tính năng

* Hiển thị thông tin cá nhân và định hướng nghề nghiệp.
* Bấm vào mục **Dự án** trên menu để xem danh sách 3 dự án học tập tiêu biểu, mỗi dự án bao gồm hình ảnh minh họa và liên kết trực tiếp.

## 4. Cách mở

1. Mở trình duyệt web bất kỳ và truy cập đường dẫn tại mục **Demo**: <https://an.github.io/portfolio/>.
2. Trên thanh menu phía trên màn hình, bấm vào mục **Dự án**.
3. Cuộn trang xuống để chọn dự án cần xem và bấm vào liên kết tương ứng trên từng dự án.

## 5. Hạn chế

* Giao diện chưa được kiểm tra và tối ưu hiển thị trên các dòng máy iPhone.
* Biểu mẫu liên hệ hiện tại mới chỉ có giao diện, chưa hỗ trợ gửi email thực tế.

## 6. Lịch sử thay đổi (Changelog / Commit Log)

* **Thêm tài liệu hướng dẫn:** Bổ sung tệp `README.md` chứa đường dẫn URL demo và các bước mở chi tiết.
* **Chuẩn hóa thư mục:** Đổi tên thư mục `Images` thành `images` (dạng viết thường) để tránh lỗi phân biệt chữ hoa/thường trên môi trường Linux của GitHub Pages.
* **Sửa liên kết CSS:** Cập nhật đường dẫn stylesheet từ `/css/styles.css` thành đường dẫn tương đối `css/styles.css` để giao diện hiển thị chính xác khi host dưới dạng subpath.
