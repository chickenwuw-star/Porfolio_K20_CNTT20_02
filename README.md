## 📌 Tính năng chính

- **Giới thiệu bản thân:** Thông tin tổng quan, định hướng nghề nghiệp và kỹ năng cá nhân.
- **Trưng bày dự án (Projects):** 
  - Hiển thị 3 dự án học tập tiêu biểu.
  - Mỗi dự án đều đi kèm hình ảnh trực quan và đường dẫn (link) tham khảo.
- **Thanh điều hướng (Navigation):** Cho phép người dùng chuyển nhanh đến phần dự án và thông tin liên hệ.

## 🚀 Hướng dẫn xem dự án

### 1. Xem trực tiếp qua Live Demo
1. Mở liên kết Demo: [https://an.github.io/portfolio/](https://an.github.io/portfolio/)
2. Bấm vào mục **Dự án** trên thanh menu chính để trải nghiệm.

### 2. Chạy dự án ở máy cục bộ (Local)
```bash
# Clone repository về máy
git clone https://github.com/an/portfolio.git

# Di chuyển vào thư mục dự án
cd portfolio

# Mở tệp index.html trực tiếp bằng trình duyệt web
```
